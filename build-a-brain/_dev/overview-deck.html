Overview · then a live demo

I built a neural network that learns colour.

  • Give it a colour. It returns the opposite colour on the wheel.
  • Nobody programmed that rule. It learned it from examples.
  • A neural network is a simplified model of the brain.
  • A real brain has billions of neurons. Mine has 256.

Each neuron takes in information, decides whether to fire, and passes a signal on to other neurons.

Step one

How does it see colour?

It does not understand names like blue or red. Every colour is turned into numbers, and those numbers go through two separate pathways.

Give it blue, and a pattern of neurons lights up in each pathway

One of those dots, close up

Inside a single neuron

If the soma decides the neuron should fire, the signal travels along the axon to the terminals, and is passed on to the output neurons.

Training

How does it learn?

  1. The correct complementary colour is given at the same time, as the target.
  2. The active neurons and the correct output are on at the same moment.
  3. So the connections between them get slightly stronger.
  4. Repeat about 4,000 times, with many different colours.

Hue error is how many degrees the answer is away from the correct colour. Close to random before training, down to a few degrees after.

Now break it

Damaging the network

  • Disable half the neurons. 128 of 256 switched off.
  • The score does not move. 85 before, 85 after.
  • The knowledge is not stored in one neuron. It is spread across many.

This is the advantage of a distributed representation. Information is spread across many neurons, which makes the network robust to damage.
